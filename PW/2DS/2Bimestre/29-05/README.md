# 🧠 Estrutura de Decisão Composta

Projeto desenvolvido com o objetivo de praticar conceitos de **Lógica de Programação**, utilizando **estruturas de decisão composta** através de exercícios interativos construídos com **HTML, CSS e JavaScript**.

Cada atividade aborda diferentes cenários do cotidiano, incentivando o desenvolvimento do raciocínio lógico e da capacidade de resolução de problemas.

---

## 📚 Exercícios Desenvolvidos

### 1️⃣ Aprovação com Recuperação

Sistema responsável por verificar a situação acadêmica de um aluno com base na nota informada.

**Regras:**

* Nota maior ou igual a **7** → Aprovado;
* Nota maior ou igual a **5** → Recuperação;
* Caso contrário → Reprovado.

---

### 2️⃣ Maioridade e Habilitação

Verifica se uma pessoa possui os requisitos necessários para dirigir.

**Regras:**

* Ter **18 anos ou mais**;
* Possuir **habilitação**.

---

### 3️⃣ Sistema de Acesso

Simula uma autenticação simples de usuário.

**Regras:**

* Usuário: `admin`
* Senha: `1234`

**Resultados possíveis:**

* Acesso liberado;
* Senha incorreta;
* Acesso negado.

---

### 4️⃣ Classificação de Temperatura

Classifica uma temperatura em diferentes categorias.

**Regras:**

* Menor que **15°C** → Frio;
* Menor que **25°C** → Agradável;
* Igual ou maior que **25°C** → Quente.

---

### 5️⃣ Caixa Eletrônico

Simula uma operação de saque bancário.

**Regras:**

* Se o valor solicitado for menor ou igual ao saldo disponível:

  * Saque realizado;
  * Exibir saldo restante.
* Caso contrário:

  * Saldo insuficiente.

## 💻 Como Executar o Projeto

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/estrutura-de-decisao.git
```

2. Acesse a pasta do projeto:

```bash
cd estrutura-de-decisao
```

3. Abra o arquivo `index.html` no navegador.

ou

4. Utilize a extensão **Live Server** no Visual Studio Code para uma melhor experiência de desenvolvimento.
